# 🐾 FurryTails - Animal Welfare Platform

A modern, responsive web application dedicated to animal welfare, rescue, and adoption. Built with React and Tailwind CSS.

🌐 **Live Demo:** [https://cool-baklava-597741.netlify.app/](https://cool-baklava-597741.netlify.app/)

## 🚀 Features

- **Responsive Design:** Works seamlessly on mobile, tablet, and desktop.
- **Interactive Map:** Integrated Google Maps to locate adoption centers.
- **Dynamic UI:** Smooth animations, counters, and dropdowns.
- **Modern Styling:** Built with Tailwind CSS for rapid and clean UI.
- **Donation & Adoption Forms:** User-friendly forms for community engagement.

## 🛠️ Tech Stack

- **Frontend:** React.js (v18)
- **Routing:** React Router DOM (v6)
- **Styling:** Tailwind CSS
- **Icons:** React Icons
- **Deployment:** Netlify
